# Renders

Zde jsou samostatné webové kopie vybraných 3D prací. Původní archiv zůstává v `Portfolio/Images` beze změn. Doporučený formát pro další soubory je WebP, AVIF nebo kvalitní JPG, dlouhá hrana přibližně 2400–3200 px podle míry detailu.

Soubory poté přiřaď projektům v `../../scripts/projects.js`.
